mogugi

瑪奇台服的免費傷害統計工具。只在本機讀取封包，不修改遊戲、不送出任何封包，資料全部留在你的電腦。

暫時讀不到版本資料，請到 GitHub releases 下載。

目前功能

傷害統計

依角色或技能看輸出，含 DPS 圖、活躍 DPS 與 BOSS CC 時間軸。

戰鬥紀錄

每場自動存下，可依副本與遊戲版本篩選。

角色與裝備

在場玩家可用名稱、公會、裝備搜尋；自己的裝備、秘法與角色數值一頁看完。

物品索引

自己所有角色、銀行、包包裡有什麼，一次查到。

遊戲內 Overlay 測試中

在遊戲畫面上顯示 BOSS CC、自己與隊伍的 CC、技能冷卻，位置自己擺。

免費使用・需加入 Discord 啟用

mogugi 完全免費，不收任何費用。第一次開啟時，需要用 Discord 帳號登入，並加入魔古工坊的 Discord 群組才能啟用。

啟用的效期是 30 天。到期後 mogugi 會請你再用 Discord 登入一次，登入後就能繼續使用，紀錄和設定都會保留；如果那時已經不在群組裡，就無法再啟用。

這樣做是為了避免有人把免費的工具拿去轉賣，也讓版本公告和問題回報集中在同一個地方，減少紛爭。

如果有人向你收費販售 mogugi，那不是我們提供的，請不要付款，並到 Discord 回報。

加入 Discord 群組

開始使用

  1. 安裝 Npcap，mogugi 靠它讀取網路封包。
  2. 下載上面的 exe 並執行。
  3. 先加入 魔古工坊 Discord 群組，第一次開啟 mogugi 時用同一個 Discord 帳號登入啟用，之後每 30 天重新登入一次。
  4. 開遊戲、進副本，打完就能在戰鬥分頁看結果。
