取樣與分數說明

頻道取樣方式

  • 量測端：新竹的一台電腦（ISP 見頁首說明），不登入遊戲；結果只代表這條線路。
  • 對象：娜歐、貝婷、愛麗沙三台伺服器，每台 CH1–CH13 與 HOUSE，共 42 個頻道，每個頻道各保持一條連線。
  • PING：每 0.5 秒送一個小封包，伺服器原樣回傳，量來回時間。
  • 每條連線用滿 5 分鐘就重新連線，換一條網路路徑；每條連線的第一筆不計（剛連上時偏高）。沒有回應的算逾時，不計入延遲。
  • 爆PING：延遲 ≥ 100 ms。實測幾乎都是封包掉了、等重傳補回，會卡約 0.3 秒；遊戲走 TCP，一個封包掉了後面都得等，所以跟體感卡頓最相關。爆PING 率是每 1000 次 PING 中的次數（‰）。
  • p50、p95：上方所選時間範圍內所有 PING 合計的統計（一半／95% 的 PING 低於這個值）；近一天的數值由直方圖推估，誤差約 2%。

對照組取樣方式

  • 對象：local節點1（家裡路由器）、HiNet節點1（中華電信第一站）、HiNet節點2（中華電信接到遊戲橘子之前的最後一站）、HiNet DNS、Cloudflare DNS，由近到遠。
  • 每 0.5 秒量一次，2 秒沒回應算逾時；和頻道同時量。兩種量法：三個路由器用 ICMP（ping），掉包時記為逾時；HiNet DNS 與 Cloudflare DNS 維持一條 TCP 連線、送 DNS 查詢，每 1 分鐘換一條線路，和頻道一樣掉包會由重傳補回、變成爆PING。每張小卡的 IP 旁標有量法。
  • 爆PING、p50、p95 的算法和頻道相同。
  • ping 是由路由器或伺服器的 CPU 回應，通常比實際線路慢一點、也比較抖；「最小」最接近線路本身的延遲。
  • 分數用和頻道同一套公式，只能看趨勢，不能拿來和頻道比較。
  • 對照組不列入伺服器總覽、熱度圖與表格。
